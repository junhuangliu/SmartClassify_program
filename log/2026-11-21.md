## [21:14:45] USART1 指令整合清单

- **目的**: 汇总当前 USART1 文本协议的全部指令、参数范围、回复与执行位置，作为上位机对接依据
- **涉及文件**: Core/Src/uart1_proto.c（解析与标志置位）、Core/Src/corexy.c / Grab.c / servo.c / WaterPump.c（执行）
- **改动摘要**: 仅文档整理，无代码改动
- **验证**: 与源码 ProcessLine 分派顺序逐条核对
- **结果**: 完成
- **备注**: 帧尾统一用 `/` 或 `\r\n`；关键字大小写不敏感；字段之间不能有空格

### 系统/调试

| 指令 | 参数 | 回复 | 说明 |
|---|---|---|---|
| `PING/` | 无 | `OK PONG` | 连通测试 |
| `STATUS/` | 无 | `STATUS COREXY=IDLE` 或 `INIT_FAIL` | CoreXY 初始化状态 |
| `switch:1` / `switch:0` | 无 | `OK SWITCH=1` / `OK SWITCH=0` | 直接调用 WaterPump_Start/Stop（沿用旧命令） |
| `$GRAB...` / `ECHO xxx` | 文本 | `$ECHO,...` / `OK ECHO,...` | uart_echo_test 联调回显钩子 |

### 任务帧（解析入队，CoreXYTask 执行）

| 指令 | 参数范围 | 回复 | 执行 |
|---|---|---|---|
| `Grab,<x>,<y>,<shape>/` | x 0~190，y 0~260，shape 0~5 | `OK GRAB X=.. Y=.. SHAPE=..`，完成后 `OK GRAB DONE` | `Grab_XY(取物点, Destination_X, Destination_Y, shape)` |
| `MoveTo,<x>,<y>/` | 数字/负值/坐标点名称；X -50~250，Y -50~300 | `OK MOVE X=.. Y=..`，到位后 `OK MOVE DONE`，下发失败 `ERR MOVE` | 100RPM / accel 40，按行程估算等待（K=1.9 + 100ms） |

`MoveTo` 示例：`MoveTo,120,30/`、`MoveTo,-15,20/`、`MoveTo,X1,Y1/`、`MoveTo,Destination_X,Destination_Y/`、`MoveTo,X1,30/`（名称与数字可混用）。

### 坐标点（直接改变量，立即生效）

| 指令 | 名称与范围 | 回复 |
|---|---|---|
| `Set,<名称>,<数值>/` | `Destination_X` 0~190、`Destination_Y` 0~260、`X0`/`X1`/`X2` -50~250、`Y0`/`Y1`/`Y2` -50~300 | `OK SET <名称>=<数值>`；名称未知 `ERR NAME`，越界 `ERR RANGE` |

默认值：Destination(100,240)、X0(0,-15)、X1(200,-15)、X2(0,165)。

### 水泵（Uart1RxTask 置标志，WaterPumpTask 执行）

| 指令 | 参数范围 | 回复 | 执行 |
|---|---|---|---|
| `Waterpump,<duty>/` | 0~100 | `OK WATERPUMP DUTY=<n>` | 运行中即时刷新 CCR；泵停时只保存数值 |
| `WaterpumpOn/` | 无 | `OK WATERPUMP ON` | 先开阀再启泵 |
| `WaterpumpOff/` | 无 | `OK WATERPUMP OFF` | 先停泵再关阀（阀门固定 67% 驱动） |

### 抓取电机 / 舵机1 动作（置标志位，GrabTask / ServoTask 执行）

| 指令 | 回复 | 执行 |
|---|---|---|
| `MDown/` | `OK MDOWN` | Grab_MotorBeginFlag=1，电机 200RPM 下转 5s 后停 |
| `MUp/` | `OK MUP` | Grab_MotorEndFlag=1，电机 200RPM 上转 5s 后停 |
| `SDown/` | `OK SDOWN` | Servo1_FallFlag=1，舵机1 下降 10 齿（-10，钳位 500~2500us） |
| `SUp/` | `OK SUP` | Servo1_RiseFlag=1，舵机1 上升 10 齿（+10） |
| `Down/` | `OK DOWN` | 同时置电机下降 + 舵机下降 |
| `Up/` | `OK UP` | 同时置电机上升 + 舵机上升 |

### 通用错误回复

`ERR CMD`（未知命令）、`ERR FRAME`（字段格式错）、`ERR RANGE`（越界）、`ERR BUSY`（任务队列满，深度 2）、`ERR LINE`（单行超过 96 字节）。
