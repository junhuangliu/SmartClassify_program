2. 安装 OpenOCD
需挂载github加速，在 PowerShell 执行：
winget install --id xpack-dev-tools.openocd-xpack
winget install --id xpack-dev-tools.openocd-xpack
winget install --id xpack-dev-tools.openocd-xpack
重开VSOCDE后检查：
openocd --version
如果提示找不到命令，查找安装位置：
Get-ChildItem "$env:LOCALAPPDATA\xpack-dev-tools","$env:ProgramFiles\xpack-dev-tools" -Recurse -Filter openocd.exe -ErrorAction SilentlyContinue
把对应的 bin 目录加入用户 PATH，或稍后在 launch.json 里用 "serverpath" 指定。

3. 调试还需要 GDB
        Cortex-Debug 调试时会调用 arm-none-eabi-gdb。只烧录可以不要，但要 F5 调试就必须装：
winget install Arm.GnuArmEmbeddedToolchain
装完确认：
arm-none-eabi-gdb --version

        4. 先验证 DAP 链路（不写 Flash）
        openocd -f interface/cmsis-dap.cfg -f target/stm32f4x.cfg -c "adapter speed 1000" -c "init; targets; shutdown"
        正常会看到类似：
        Info : CMSIS-DAP: SWD supported
        Info : CMSIS-DAP: Interface Initialised (HID)
        Info : STM32F4xx...
        Info : Examined Cortex-M...
        看到这些说明 DAP、接线、目标板都通了。
        如果识别不到设备，可显式指定 VID/PID：
        openocd -f interface/cmsis-dap.cfg -c "cmsis-dap vid_pid 0x04d8 0x00df" -f target/stm32f4x.cfg -c "init; targets; shutdown"

opencode配置

步骤 A：安装 Node.js（唯一的必备）
    opencode 运行依赖 Node.js。
1. 打开 nodejs.org (https://nodejs.org)，下载 LTS 版本（左边的「LTS」按钮）
2. 按默认选项一路「下一步」安装（不用改安装路径也没问题）
3. 安装完成后，去 VS Code 验证
在 VS Code 里：
1. 打开任意一个文件夹（菜单 文件 > 打开文件夹，随便建个空文件夹即可）
2. 按  Ctrl + ` （或 终端 > 新建终端）打开集成终端
3. 输入以下命令并回车：
node -v
npm -v
预期：都输出版本号（例如 v22.x.x、10.x.x）。只要有版本号就说明成功。
步骤 B：首次启动 opencode
在同一个 VS Code 集成终端里，直接运行：
npx opencode@latest
首次运行会自动下载，稍等片刻即可进入 opencode 的 TUI 界面。
